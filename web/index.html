    GPU Kernel Runtime · GPU執行時間

    SGEMM資料以14個GPU設定描述矩陣乘法效能，四次Run為毫秒計時結果，本作業以其平均作Target並排除於輸入。[A1] Ballester-Ripoll等人的相關研究使用對數時間、Tensor Train代理模型與Sobol敏感度分析；其模型的一階效應合計不到四分之一，提示交互作用值得考慮。[A2 §8.3] 但該研究的12080個設定與25次計時不同於本作業241600列、四次Run，不能把其變異比例或誤差當作本作業結果。據此，本作業保留原始特徵加法OLS作能力有限的案例，並忠實呈現已凍結的評分、負時間及區間限制；此定位不否定加入轉換或交互作用項的其他線性模型。

    本作業採用：採14個設定與四次Run平均Target；以原始特徵OLS呈現限制，保留已完成的log補充分析。正式split為development 193280／test 48320，test R² 0.409873、RMSE 285.227 ms。

    未採用及理由：未實作Tensor Train／Sobol分析，也不依已揭露test新增高階調模；未採外部12080設定、25次計時或70/15/15切分，未把其3.4%相對誤差當成本作業分數。

    A1 原始來源（UCI Dataset Information / Additional Variable Information） · A2 原始來源（arXiv 1712.00233 local16-page PDF §8.3, pp12–14; Tables6–9）

    Student Performance · 學生葡萄牙語成績

    UCI學生資料包含數學與葡萄牙語兩科；G1、G2為第一、第二評量期成績，G3為最後評量期的年度成績，前期成績與G3有強相關。[B1] Qiang等人的研究以395筆數學資料及30個背景特徵建立ANN，結合SHAP解釋與SPPE領域知識約束，提供預測能力與解釋性並重的既有解法。[B2 摘要／方法] 本作業採649筆葡萄牙語資料，主版本含G1／G2，另以背景版比較資訊差異；兩者不能直接移植該文的準確率或RMSE。本作業採參考類別dummy編碼與五種特徵選擇後OLS，不採ANN／SHAP／SPPE。由於背景欄位的可用時點未全部證實，結果僅作條件關聯分析，不宣稱開學預警或教育干預的因果效果。

    本作業採用：採student-por 649列、G3 Target；主版本32原始X→41 encoded，背景版30→39。每個training fold內學習類別、dummy編碼與標準化；主代表選G1／G2後OLS，test R² 0.928986。

    未採用及理由：未採B2的Label Encoding、ANN、SHAP或SPPE；本作業五方法為SelectKBest、RFE、Forward SFS、Lasso與ElasticNet selection，皆接OLS。未讀取B3全文，不補寫其方法；不移植外部分數或宣稱因果效果。

    B1 原始來源（UCI Dataset Information / Additional Variable Information） · B2 原始來源（DOI10.1038/s41598-026-40538-y Abstract / Methodology / Data understanding and pre-processing / Sensitivity analysis of feature encoding schemes / Discussion）

    已修正原輸出的Label Encoding、五方法清單及GPU未訓練等錯誤；外部研究的變異比例與分數均不當成本作業結果。下載完整摘要與核對紀錄。原始貼文僅本機保存。
