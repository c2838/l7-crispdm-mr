# 階段5提案：沿用DIC2的互動分析網站

狀態：使用者「Ok, 階段5 go」已核准，本機範圍已完成，見STAGE5_RESULTS.md。以下為原核准範圍與完成checklist；正式模型／test保持凍結，階段6與公開發布仍待對應確認。

## 目標與版型

讓老師進站就能切換兩份正式資料，看到方法比較、單筆預測、CI／PI與完整CRISP-DM。沿用已唯讀檢視的L5V2 DIC2版型：頂端導覽與Dataset選單、hero、方法與特徵數操作、指標卡、兩張比較曲線、比較表、公式、係數／預測雙欄、殘差與learning curve、CRISP-DM／來源。只調整配色、留白及必要新區塊，圖表維持英文優先、中文輔助。

首頁兩題是GPU Runtime（14原始輸入）與Student Performance（32原始輸入）。每題另有預先規劃的補充版本：log時間／背景資料。補充不是第三、第四份資料；學生背景版移除G1/G2後為30原始欄位。頁面分開顯示原始、編碼後及選取數量。

## GPU案例定位（已由使用者確認）

使用者確認保留GPU作為原始特徵下加法式多元線性回歸能力有限的案例；重點為方法應用、實作、正確評估與忠實呈現，不以提高R²為目標擴充模型或更換資料。這不等於否定所有轉換或交互作用形式的線性模型。既有模型、切分與正式測試結果不變；本階段的候選展示資料準備只為既有方法／k互動，不新增追求高R²的模型改善實驗。
