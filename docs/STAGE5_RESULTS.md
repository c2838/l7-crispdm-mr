# 階段5結果：DIC2版型的兩題互動分析網站

日期：2026-11-01。使用者「Ok, 階段5 go」核准後完成本機範圍。網站入口為`web/index.html`；這不代表公開網站、任意Dataset加分或最終繳交已完成。

## 已實作的使用流程

- 沿用DIC2的頂端資料選單、hero、方法／特徵控制、指標、雙比較曲線、比較表、公式、係數／預測雙欄、殘差／學習曲線及CRISP-DM布局；改為深藍綠配色，維持英文圖表優先、中文說明。
- GPU與學生兩題下拉切換；每題另有事先規劃的log時間／背景資料補充版本。各版本的原始、編碼後與選取欄位數分開呈現。
- 五種選取→OLS：SelectKBest、Forward SFS、RFE、Lasso、ElasticNet。前三者可探索既定k；後兩者依alpha／l1_ratio及真實非零數呈現，不以假k補零。
- Compare All比較開發CV曲線；凍結比較表包含Dummy、全特徵OLS、五選取方法、Ridge及Lasso預測模型。圖表候選可用滑鼠或Enter選取。
- 切換候選會更新公式、欄位、係數、95%區間及診斷。正式測試卡僅對應原先已凍結的各方法勝出模型；其他候選顯示原CV及development擬合詳情，不額外評分test。
- 單筆輸入接受數值／類別，依當前真實模型計算點預測、95%位置CI、觀測PI及HC3位置CI。未知類別、缺值填補、外推、未觀察離散值、非數字及溢位均有處理。
- 正式模型呈現全test計算的PI覆蓋率與寬度；非勝出候選只展示development樣本區間，不冒稱獨立測試覆蓋。Dummy／正則化預測不硬套OLS區間。
- 提供原尺度encoded／標準化係數及classical／HC3切換、殘差、Q-Q、VIF、影響點、學習曲線、來源與授權。比較CSV及當前模型／區間JSON已可實際下載。
- CRISP-DM六段都有本案內容，Deployment明示本機展示與公開驗證待完成。GPT輔助與NotebookLM位置有清楚標示；研究、PDF及GitHub尚未完成的項目沒有假連結或假摘要。

## GPU案例定位與統計誠實性

依D25，保留GPU為「目前原始特徵下加法線性模型能力有限」案例，不新增追求高R²的模型家族、換資料或重切test。負時間、超界區間、異質變異、殘差分布及選擇後推論限制均保留；log位置清楚標成幾何位置，HC3不聲稱可修復觀測PI。

學生題高R²同樣標示需前期成績、回顧條件估計、非因果與非開學預警。不同題的RMSE不能直接排名。Adjusted R²只報適用的development OLS；log版本是log反應尺度。

## 實作與重現

- `web/index.html`、`style.css`：沿用DIC2布局的本案內容及響應式樣式。
- `web/app.mjs`、`charts.mjs`：原生JavaScript與SVG互動，不依賴外部圖表CDN或前端框架。
- `web/prediction.mjs`：凍結前處理、完整精度係數、原尺度方程、共變異矩陣與Student-t臨界值的可攜式推論。
- `web/data/`：按情境與候選分檔、按需載入；約79.51MB十進位，首頁不一次載入全部488候選。GPU代表詳情約0.75MB、學生約0.18MB，來源情境摘要約0.05～0.13MB。
- `scripts/export_stage5.py`：development候選與learning curve；已有catalog時拒絕覆寫，重建前須先保留舊版本。
- `scripts/prepare_stage5_intervals.py`：用保存方程補development顯示點區間，不重新fit，也不讀取新test列。
- `scripts/verify_stage5.mjs`、`verify_stage5_data.py`：實際數值與來源核對。
- `scripts/preview_stage5.py`：僅監聽127.0.0.1的靜態預覽，停用開發快取。執行`.venv/bin/python -B scripts/preview_stage5.py`後開啟`http://127.0.0.1:8767/`。

本機預覽實際HTTP回應200，已在瀏覽器操作。這是已執行的驗收，重現指令不是要求使用者補跑才能算完成。預覽不提供正式API，且不是Vercel驗證；自訂Dataset仍待階段6。

## 遇到並解決的問題

1. **任意k缺乏完整詳情**：原本只保存方法勝出模型；以同一training-only路徑補齊既定候選，保留凍結test，避免假互動或偷用其他k的公式。
2. **數字溢位被瀏覽器轉為空白**：原生number欄位把`1e309`清空，會誤走缺值填補。改為帶decimal輸入提示的文字欄位，由數值驗證保留原字串並拒絕非有限值，標示aria-invalid；空白仍依明示規則填補。
3. **靜態程式快取**：修正後曾仍載入舊模組。核對實際HTTP內容與檔案SHA後，加入資產版本；預覽工具停用快取，瀏覽器確認載入stage5-3。
4. **手機長座標及不合理的顯示範圍**：縮短排序軸標籤，特徵數／樣本序與RMSE座標限制在非負範圍；真正負預測與PI端點仍保留。
